# Screenshot Placeholders

This directory contains placeholder files for documentation screenshots.

## Required Screenshots

1. **docker-compose-running.png** - Docker Compose startup
2. **landing-page.png** - Main landing page
3. **focus-mode.png** - Live focus mode interface
4. **dashboard.png** - Progress dashboard
5. **api-docs.png** - FastAPI documentation

## Instructions

1. Run `docker-compose up --build`
2. Take screenshots of each interface
3. Replace these placeholder files with actual screenshots
4. Update README.md if needed

## Screenshot Guidelines

- Use high resolution (1920x1080 or higher)
- Ensure good lighting and contrast
- Include relevant UI elements
- Crop to focus on important content
- Use consistent naming convention
